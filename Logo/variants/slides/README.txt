Srivastava Lab — logo with the group name
=========================================

For slides, posters, letterheads, email signatures — anywhere the name is
needed alongside the mark. Mark, "Srivastava Lab", a hairline rule, then the
department line, all on one row. Transparent background, so it sits on any
slide colour.

Using them
----------

Drop the PNG straight into PowerPoint or Keynote and scale it — hold shift so
both axes scale together, never stretch one. Leave clear space around it of at
least the width of the disc. Don't recolour it, add effects, or set it on a
busy photograph; use the reverse version on anything dark.

Pick the size at or above the pixel width you will actually display, so it
never has to be scaled up. The SVG is better still wherever it's accepted.

The text is converted to outlines, so these render identically on any machine
whether or not the fonts are installed. The wordmark is TeX Gyre Pagella (a
Palatino), the department line TeX Gyre Heros.

Colours: amber #c9812f, teal #0f6e78, near-black #111820, disc #e8f2f2,
         rule #c8d0d8, department line #6b7885.
On the reverse versions: disc #15333c, strands #5ec6d2 and #eef4f6,
         rays #e8a24c, department line #aab4be.
