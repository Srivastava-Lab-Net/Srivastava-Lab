Software

Graphical application · Windows and macOS

Dynamic light scattering GUI

A graphical interface for dynamic light scattering data reduction, written to make correlation-function analysis approachable without scripting. The distribution includes a sample data file and a manual, and the source is available under version control.

Download — Windows and macOS Source on GitHub

Cite: M. Salazar, H. Srivastav, A. Srivastav, S. Srivastava. A user-friendly graphical user interface for dynamic light scattering data analysis. Soft Matter 19, 6535 (2023). PDF
